# ZanWatch

Мониторинг изменений законодательства РК: бухучёт, налоги, зарплата и взносы, страхование, аудит.
По каждому изменению — короткая карточка: **суть**, **было → стало**, **что сделать** со сроками и ссылка на первоисточник.
Требования — в [PRD.md](PRD.md).

## Запуск

Нужен Python 3.11+.

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # без ключа — разбор только по правилам
export ZW_ADMIN_TOKEN=...
uvicorn app.main:app --host 0.0.0.0 --port 8000
python -m app.pipeline              # ручной сбор (можно --source adilet)
pytest -q                           # тесты
```

В Windows PowerShell переменные задаются так: `$env:ZW_ADMIN_TOKEN = "..."`.

Откройте http://localhost:8000 — это PWA: на телефоне её можно «Установить на главный экран».

Запуск сбора через API:

```bash
curl -X POST http://localhost:8000/api/collect -H "X-Admin-Token: $ZW_ADMIN_TOKEN"
```

## Публикация в интернете (Render)

В репозитории есть `render.yaml`. Откройте
https://render.com/deploy?repo=https://github.com/zhunussovaraushan1-ctrl/zakon,
войдите в Render через GitHub и нажмите **Deploy Blueprint**. `ANTHROPIC_API_KEY` можно ввести там же или оставить пустым.
Токен `ZW_ADMIN_TOKEN` Render сгенерирует сам (виден в настройках сервиса → Environment).

Ограничения бесплатного тарифа: сервис засыпает после 15 минут без запросов (первое открытие ~1 минута),
а файл SQLite стирается при каждом перезапуске — для постоянного хранения нужен платный диск или PostgreSQL.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ Claude API. Нет ключа — сводки строятся по правилам |
| `ZW_LLM_MODEL` | `claude-opus-5-5` | Модель для сводок |
| `ZW_ADMIN_TOKEN` | `change-me` | Токен для `POST /api/collect`. **Смените!** |
| `ZW_COLLECT_INTERVAL_HOURS` | `0` | Сбор по расписанию каждые N часов (0 — выключен) |
| `ZW_REQUEST_DELAY_SEC` | `2` | Пауза между запросами к одному сайту |
| `ZW_MAX_DOCS_PER_SOURCE` | `30` | Сколько ссылок брать из ленты источника за проход |
| `ZW_SEED_DEMO` | `1` | Демо-карточки. `0` — убрать их из базы при старте |
| `ZW_DB_PATH` | `./zanwatch.db` | Путь к SQLite |

## Устройство

```
Источники → Сбор списка → Фильтр по заголовку → Загрузка текста → Фильтр по тексту
         → Разбор правок по правилам → ИИ-сводка (Claude) → SQLite → FastAPI → PWA
```

| Файл | Что делает |
|---|---|
| `app/config.py` | Настройки, справочники сфер и ролей, **разметка сайтов-источников** |
| `app/collector.py` | robots.txt, паузы, User-Agent, разбор ленты и текста документа |
| `app/classifier.py` | Словари по сферам с весами: фильтр по заголовку и по тексту, роли |
| `app/amendments.py` | «Было/стало» по шаблонам «заменить / изложить / дополнить / исключить», дата вступления в силу |
| `app/summarizer.py` | Сводка через Claude API (JSON-схема, проверка ответа) или по правилам |
| `app/pipeline.py` | Конвейер и журнал запусков (`runs`) |
| `app/main.py` | API и раздача интерфейса |
| `app/demo.py` | 7 демо-карточек (помечены «Демо») |
| `app/static/` | Интерфейс: один HTML на чистом JS, manifest, service worker |

### ИИ-сводка

- Модель получает текст документа и подсказки, найденные правилами (правки, дата вступления в силу).
- Ответ ограничен JSON-схемой и дополнительно проверяется: неверные даты обнуляются, пустые поля не заполняются догадками.
- Включён серверный fallback (`fallbacks: "default"`, beta `server-side-fallback-2026-07-01`): если основная модель отклонит запрос, его обработает запасная. Отключается удалением этих параметров в `summarizer.py`.
- Любая ошибка ИИ — сводка строится по правилам, конвейер не останавливается.

## Перед первым боевым сбором

Адреса лент и CSS-селекторы в `app/config.py` заданы по типовой вёрстке и **не сверялись с живыми сайтами**.
Для каждого источника откройте ленту, проверьте `list_url`, `item_selector`, `link_selector`, `date_selector`, `text_selector`
и запустите `python -m app.pipeline --source <ключ>`. Источники с ошибками видны в `runs.stats.failed_sources`.
